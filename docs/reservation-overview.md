# レストラン予約システム

## 概要
このプロジェクトは、顧客がメニューを選択したあとに、空いている日付と時間を選んで予約できるレストラン予約システムです。  
予約日が近づいた際には、失念防止・キャンセル防止のための通知を送ります。  
また、店舗側は予約一覧、来店状況、キャンセル状況を管理できます。

---

## 主な機能

### 顧客向け
- メニュー選択
- 人数選択
- 空き日時表示
- 予約登録
- 予約確認
- キャンセル
- 予約確認通知
- リマインド通知

### 店舗向け
- 今日の予約一覧
- 日付別予約一覧
- 予約詳細確認
- 来店済み／キャンセル／無断キャンセル管理
- メニュー管理
- 営業日・営業時間設定
- 通知設定

---

## このシステムの目的
- 顧客が分かりやすく予約できるようにする
- 空き枠を正確に表示する
- 予約忘れや無断キャンセルを減らす
- 個人情報を安全に管理する
- 店舗側の運用負担を減らす

---

## 想定する予約フロー
1. 顧客がメニューを選ぶ
2. 顧客が人数を選ぶ
3. システムが空いている日付と時間を表示する
4. 顧客が日時を選ぶ
5. 顧客情報を入力する
6. 予約を確定する
7. 予約確認通知を送る
8. 予約日が近づいたらリマインド通知を送る

---

## 想定技術構成
- Frontend: Next.js
- UI: Tailwind CSS
- Backend: Next.js API または Supabase Edge Functions
- Database: Supabase PostgreSQL
- Auth: Supabase Auth または管理画面専用認証
- Hosting: Vercel
- Notification: メール送信サービス（将来 LINE / SMS 拡張可）
