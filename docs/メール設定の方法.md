# メール設定の方法

このアプリでは **入庫登録時** に、入庫担当者・出庫担当者へ登録内容をメールで送るためにSMTPを設定します。未設定の場合はメール送信をスキップします。

---

## 方法1：画面から設定（推奨）

1. サイドメニューから **「設定」** を開く
2. 設定ページで **「メール設定（入庫登録時の通知用）」** のセクションまでスクロール
3. 次の項目を入力する  
   - **SMTPホスト** … 例: `smtp.gmail.com`  
   - **ポート** … 通常 `587`（SSL 465 の場合は 465）  
   - **ユーザー（メールアドレス）** … 送信に使うメールアドレス  
   - **パスワード** … そのメールのパスワード（またはアプリパスワード）  
   - **送信元アドレス（From）** … 受信者に表示される送信元（空の場合はユーザーと同じ）
4. **「メール設定を保存」** をクリック

**Gmail の場合**

- SMTPホスト: `smtp.gmail.com`  
- ポート: `587`  
- ユーザー: 自分のGmailアドレス  
- パスワード: **アプリパスワード**（通常のログインパスワードではなく、Googleアカウントで「2段階認証」を有効にしたうえで発行したアプリパスワード）

---

## 方法2：環境変数で設定

サーバー起動時に環境変数で指定することもできます。  
（設定画面で保存した内容がある場合は、そちらが優先されます。）

| 環境変数   | 内容例 |
|------------|--------|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | 送信用メールアドレス |
| `SMTP_PASS` | パスワード（またはアプリパスワード） |
| `MAIL_FROM` | 送信元表示用（省略時は SMTP_USER を使用） |

`.env.local` に書く例:

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=your-app-password
MAIL_FROM=noreply@yourdomain.com
```

---

## 担当者へのメール送信について

- **受付担当者・現場処理担当者・入庫担当者** の「名前」と「メールアドレス」は、同じ設定ページの **「受付担当者」** などのセクションで登録します。
- 入庫登録時に、**出庫担当者** として選んだ担当者のメールアドレスに、登録内容が送信されます。
- メール設定（SMTP）が未設定の場合は送信されず、「メール送信をスキップ」となります。
