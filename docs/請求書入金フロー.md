# 請求書発行〜入金〜自動照合フロー

## 流れ

1. **請求書発行** … 請求書を印刷した案件が「請求書発行した案件」として記録される
2. **入金** … 実務でお客様から入金がある
3. **銀行API** … 入金データの取得元（手動登録・CSV・または外部APIのURL）
4. **入金取得** … 銀行入金データを登録する、または API URL から取得する
5. **案件と自動照合** … 登録済み入金データと**請求書発行した案件**の6項目で照合する
6. **ステータス更新** … 一致した案件を「入金済」に更新する

請求書発行履歴・自動照合の対象は「完了・見積中」のステータスではなく、**請求書を1回以上印刷（発行）した案件**です。

## 照合に使う6項目

- 請求書作成日（登録日）
- 受付番号（請求書No）
- 御社指定No
- 請求先宛名
- 郵便番号
- ご請求金額（税込）

すべて一致した案件のみ「入金済」に更新されます。

## 使い方

### 入金データの登録方法（いずれか）

- **手動** … 銀行設定 → 銀行入金データ設定で1件ずつ登録
- **CSV** … 銀行入金データ設定でCSVを貼り付けて一括取り込み
- **銀行API** … 銀行設定 → 入金取得（銀行API）でAPIのURLを指定し「取得して登録・自動照合」を実行

### 自動照合の実行

- **請求書発行履歴** … 「自動照合を実行」ボタンで、登録済み入金データと全案件を照合し、一致した案件を入金済に更新
- **銀行APIから取得時** … 「取得して登録・自動照合」で取得と登録のあと、同じ流れで自動照合まで実行

### 銀行APIのレスポンス形式

`GET` または `POST` で次のいずれかを返すURLを指定できます。

- 配列: `[{ "invoiceDate", "receptionNo", "specifiedNo", "recipientName", "postalCode", "amount" }, ...]`
- オブジェクト: `{ "payments": [ ... ] }`

日付は `yyyy-MM-dd` または `yyyy/mm/dd`、金額は数値または文字列でかまいません。

## 経理担当者

銀行設定・入金取得（API）・銀行入金データ設定は、設定で「経理担当」にチェックされたユーザーのメール・パスワードでログインすると利用できます。
