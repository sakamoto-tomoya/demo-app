# メール送信（SMTP）の設定方法

入庫登録時に、出庫担当者へ「入庫した」とメールで通知するための設定です。

---

## 方法1: 設定画面から設定（推奨）

1. アプリの **設定** ページを開く
2. **「メール設定（入庫登録時の通知用）」** のセクションまでスクロール
3. 次の項目を入力して **「メール設定を保存」** をクリック

| 項目 | 説明 | 例 |
|------|------|-----|
| **SMTPホスト** | メールサーバーのアドレス | `smtp.gmail.com`（Gmail）<br>`smtp.office365.com`（Outlook）<br>社内サーバーの場合は担当者に確認 |
| **ポート** | 通常は **587**（TLS）または **465**（SSL） | `587` |
| **ユーザー（メールアドレス）** | SMTPログイン用のメールアドレス | `your@example.com` |
| **パスワード** | SMTP用のパスワード（Gmailの場合は「アプリパスワード」） | — |
| **送信元アドレス（From）** | 通知メールの差出人表示（空ならユーザーと同じ） | `noreply@example.com` |

保存後、設定はプロジェクト内の **`data/email-config.json`** に保存されます。

---

## 方法2: 環境変数で設定

サーバーや本番環境で環境変数を使う場合です。**設定画面で保存した内容がある場合は、そちらが優先**されます。

プロジェクト直下に **`.env`** または **`.env.local`** を作成し、次を記述します。

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=アプリパスワード
MAIL_FROM=your@gmail.com
```

| 環境変数 | 必須 | 説明 |
|----------|------|------|
| `SMTP_HOST` | ○ | SMTPサーバーのホスト名 |
| `SMTP_PORT` | — | ポート（省略時は 587） |
| `SMTP_USER` | ○ | ログイン用メールアドレス |
| `SMTP_PASS` | ○ | パスワード |
| `MAIL_FROM` | — | 送信元（省略時は `SMTP_USER` と同じ） |

---

## Gmail を使う場合の注意

- 通常のログインパスワードでは送信できないことがあります
- **Googleアカウント** → **セキュリティ** → **2段階認証を有効**にしたうえで、**「アプリパスワード」** を発行し、そのパスワードを **パスワード** 欄に入力してください

---

## 送信先（出庫担当者）について

- メールは **入庫フォームで選択した「出庫担当者」** のメールアドレスにだけ送られます
- 出庫担当者の **名前** と **メールアドレス** は、設定の「受付／現場／入庫担当者」のいずれかに登録しておく必要があります
- 名前が完全一致している必要があります（表記ゆれに注意）

---

## 動作確認

1. 上記のどちらかでSMTPを設定
2. 設定で出庫担当者に「名前」と「メールアドレス」を登録
3. **部品入庫** ページで入庫担当者・出庫担当者を選び、**登録** をクリック
4. 成功すると「メールを送信しました」、失敗すると理由が表示されます

送信に失敗した場合は、画面に表示される **失敗理由** を確認し、SMTPの設定や担当者メールの登録を見直してください。
